一、项目简介
────────────────────────────────────────────────────────────────────
一个单文件、零构建的个人作品集网站。整站只有 index.html 一个页面
（约 62 KB，内联 CSS + JS），配 assets/ 目录下的图片素材。

页面风格：深色电影感底图 + 极简排版 + 毛玻璃质感面板。
导航不是滚动锚点，而是「点一下换一整屏」——五个页面各自占满视口，
不会出现一长条需要一直往下滚的版面。


二、快速预览
────────────────────────────────────────────────────────────────────
方式一（最简单）
  1. 打开 personal_portfolio 文件夹
  2. 双击 index.html

方式二（推荐，避免个别浏览器拦截本地资源）
  用 VS Code 打开该文件夹 → 右键 index.html → Open with Live Server
  或用任意静态服务器，例如：
     python -m http.server 8000
  然后访问 http://127.0.0.1:8000/index.html

注意：页面需要联网才能显示完整效果，原因见第九节。

五、视觉与实现说明
────────────────────────────────────────────────────────────────────
排版与视觉
  · 字体：Inter 可变字体（opsz 14–32 / wght 100–900）
  · 主标题使用 display 光学尺寸（opsz 32），字重 410
  · 深色底 #0a0d12；面板为半透明深灰 + backdrop-filter 毛玻璃 + 内描边
  · 强调色仅用于交互高亮，整体保持黑白灰克制配色
  · 所有文字带轻微投影，保证压在视频背景上依然清晰可读

代码结构
  · 单文件、纯 HTML / CSS / JS，不依赖任何框架或第三方库
  · 首页与子页面共用同一套设计变量（圆角、间距、字距、字重），
    改一处变量即可全站生效
  · 入场动效仅在首次加载时播放一次，播完自动移除动画类，不影响后续操作


六、响应式断点
────────────────────────────────────────────────────────────────────
共四套架构，自动切换：

  1. 桌面（默认）
     基于 1560 × 1008 参考坐标系等比缩放，版式随窗口整体缩放、
     不会被裁切。导航横向完整展开。

  2. 平板（宽 600–1180 且高 ≥ 600）
     改为流式布局，标题单行，导航四项 + 「查看作品」全部可见。

  3. 紧凑 / 手机（宽 ≤ 599，或高 ≤ 599 且宽 ≤ 1180）
     导航收起为汉堡菜单，内边距避开刘海与手势区（safe-area 适配）。

  4. 超矮视口（宽 ≤ 1180 且高 ≤ 560）
     进一步压缩标题与间距，防止内容溢出。


七、交互说明
────────────────────────────────────────────────────────────────────
  · 导航、页内链接：整屏切换页面（hash 路由，支持前进 / 后退）
  · 移动端菜单：纯 CSS 展开 / 收起，无需 JS
  · 项目作品素材胶囊：点击弹出大图查看

  · 已适配系统「减少动态效果」偏好（prefers-reduced-motion）

十、常见修改指引
────────────────────────────────────────────────────────────────────
  改文案
    直接在 index.html 里搜索原文字，就地替换即可。

  换 / 加项目图片
    1) 图片放进 assets/
    2) 在主图位置改 <img src="assets/文件名">
    3) 若同一项目有多张备选图，做成胶囊链接：
       <a class="wp-chip" data-lightbox="assets/xxx.jpg" data-caption="说明文字">
       lightbox 会自动接管，无需写额外 JS。

  调整某个页面的版式
    先改 CSS 变量（间距、字号、圆角集中在文件顶部 :root 中），
    再动具体规则，能减少改一处崩一片的情况。

  换背景视频
    搜索文件中 cloudfront 的地址并替换为新链接。


十一、已知说明
────────────────────────────────────────────────────────────────────
  · 站点为纯静态页面，无后端、无数据收集、无表单提交。
  · 如需部署上线，把整个 personal_portfolio 文件夹上传到任意静态托管
    （GitHub Pages、Vercel、Netlify、对象存储等）即可，无需构建步骤。
  · 建议保持 index.html 与 assets/ 的相对目录关系不变，否则图片会失效。
